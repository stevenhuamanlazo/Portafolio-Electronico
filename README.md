## Tecnologías

HTML5 · CSS3 · JavaScript (sin frameworks) · Git y GitHub Pages

## Estructura

```
├── index.html          Portafolio
├── index.css / index.js  Estilos y comportamiento de la portada
├── cuaderno.html       Cuaderno semanal
├── cuaderno/
│   ├── css/  js/       Estilos y scripts del cuaderno
│   └── semanas/        Una ficha por semana (semana-01.html …)
└── assets/             Imágenes y evidencias por semana (Sem01 …)
```

## Ejecutar en local

El cuaderno carga las semanas con `fetch`, así que debe abrirse con un servidor local (por ejemplo, la extensión **Live Server** de VS Code) y no con doble clic en el archivo.
